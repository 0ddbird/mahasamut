# Vowels

A vowel is written around its consonant, shown here as ◌: before it, after it,
above or below it, or on several sides at once. Learn each vowel as a whole
shape, like "eau" in French, rather than letter by letter.

Each row pairs a short vowel with its long one. The names follow the
romanization of the game, where a doubled letter means a long vowel.

## Simple vowels

| Short | | Long | |
| :-: | :-: | :-: | :-: |
| ◌ะ | a | ◌า | aa |
| ◌ิ | i | ◌ี | ii |
| ◌ึ | ue | ◌ือ | uee |
| ◌ุ | u | ◌ู | uu |
| เ◌ะ | e | เ◌ | ee |
| แ◌ะ | ae | แ◌ | aee |
| เ◌าะ | or | ◌อ | oor |
| เ◌อะ | oe | เ◌อ | oee |
| โ◌ะ | o | โ◌ | oo |

## Composed vowels

| Short | | Long | |
| :-: | :-: | :-: | :-: |
| ◌ัวะ | ua | ◌ัว | uua |
| เ◌ียะ | ia | เ◌ีย | iia |
| เ◌ือะ | uea | เ◌ือ | ueea |

The short form of a vowel often ends with ◌ะ.

## Special vowels

| | | | |
| :-: | :-: | :-: | :-: |
| ◌ำ | am | ไ◌ | ai (mai malai) |
| ใ◌ | ai (mai muan) | เ◌า | ao |

- They are short vowels with a final sound of their own: /m/ for ◌ำ, /y/ for
  ใ◌ and ไ◌, /w/ for เ◌า. A syllable written with one of them is live, as if it
  ended in a sonorant final (น้ำ, ไม่).
- ใ◌ and ไ◌ sound the same; ใ◌ is only used in a handful of words.

## Rare vowels

| | | | |
| :-: | :-: | :-: | :-: |
| ฤ | rue, ri, roe | ฦ | lue |
| ฤๅ | ruue | ฦๅ | luue |

They are written as letters of their own, and are hardly ever used: the game
leaves them out.
