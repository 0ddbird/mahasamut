# Tones

The tone of a syllable comes from three things: the class of its first
consonant, whether the syllable is live or dead, and its tone mark.

- **Live** syllables end in a long vowel, or in a sonorant final (ม น ง ย ว).
- **Dead** syllables end in a short vowel, or in a stop final (ก ด บ).
- The four tone marks: ◌่ mai eek, ◌้ mai tho, ◌๊ mai trii, ◌๋ mai djattawaa.

The same mark does not give the same tone in every class: with a low class
consonant, ◌่ gives a falling tone and ◌้ a high tone.

## Mid class

| | Mid → | Low ↘ | Falling ↗↘ | High ↗ | Rising ↘↗ |
| :-- | :-: | :-: | :-: | :-: | :-: |
| Live | กา | ก่า | ก้า | ก๊า | ก๋า |
| Dead | | กะ | ก้ะ | ก๊ะ | |

- Every tone has its mark: ◌่ low, ◌้ falling, ◌๊ high, ◌๋ rising.
- A dead syllable is low without a mark.

## High class

| | Mid → | Low ↘ | Falling ↗↘ | High ↗ | Rising ↘↗ |
| :-- | :-: | :-: | :-: | :-: | :-: |
| Live | | ข่า | ข้า | | ขา |
| Dead | | ขะ | ข้ะ | | |

- A live syllable is rising without a mark.
- A dead syllable is low without a mark.
- ◌๊ and ◌๋ are only written on mid class consonants.

## Low class

| | Mid → | Low ↘ | Falling ↗↘ | High ↗ | Rising ↘↗ |
| :-- | :-: | :-: | :-: | :-: | :-: |
| Live | คา นา | | ค่า น่า | ค้า น้า | |
| Dead | | | ค่ะ น่ะ | คะ นะ | |

- A live syllable is mid without a mark.
- A dead syllable without a mark depends on its vowel: high with a short vowel
  (คะ), falling with a long one (คาด).
- ◌่ gives a falling tone and ◌้ a high tone.

## Five tones with twin consonants

A low 1 consonant and its high twin sound the same: together, they write the
five tones.

| Mid → | Low ↘ | Falling ↗↘ | High ↗ | Rising ↘↗ |
| :-: | :-: | :-: | :-: | :-: |
| คา | ข่า | ข้า ค่า | ค้า | ขา |

## Five tones with a silent ห

A low 2 consonant has no high twin. A silent ห before it makes it follow the
high class rules, which gives the missing tones.

| Mid → | Low ↘ | Falling ↗↘ | High ↗ | Rising ↘↗ |
| :-: | :-: | :-: | :-: | :-: |
| นา | หน่า | หน้า น่า | น้า | หนา |
| ยา | หย่า | หย้า ย่า | ย้า | หยา |
